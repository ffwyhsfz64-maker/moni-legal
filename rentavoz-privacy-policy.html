Última actualización: 31 de agosto de 2026

1. Información que recopilamos

RentaVoz recopila únicamente la información necesaria para ofrecer el servicio:

  • Cuenta: correo electrónico y nombre de usuario al registrarse.
  • Reseñas: dirección, fechas, monto de renta, calificaciones, fotos y comentarios que el usuario elige publicar.
  • Comprobante de domicilio (opcional): imagen o PDF para verificar la estadía. Se procesa con Google Cloud Vision solo para validar texto de fecha; no se almacena el contenido OCR.
  • Ubicación: solo cuando el usuario presiona "Usar mi ubicación". No se rastrea en segundo plano.

2. Cómo usamos la información

  • Mostrar y gestionar reseñas en el feed y el mapa.
  • Verificar la autenticidad de las reseñas mediante el comprobante.
  • Traducir reseñas a otros idiomas bajo demanda del usuario.
  • Mejorar la estabilidad de la aplicación (Firebase Crashlytics).

3. Compartición de datos

No vendemos ni cedemos datos personales a terceros. Utilizamos los siguientes servicios de Google bajo sus propias políticas de privacidad:

  • Firebase Authentication, Firestore, Storage
  • Google Maps Platform
  • Google Cloud Vision API (comprobante)
  • Google Cloud Translation API

4. Reseñas públicas

Las reseñas publicadas son visibles para todos los usuarios (iOS y Android). El nombre de usuario aparece junto a la reseña. Si deseas eliminar tu reseña, puedes hacerlo desde "Mi perfil" en cualquier momento.

5. Retención y eliminación

Puedes eliminar tu cuenta y todas tus reseñas enviando un correo a jgh1775@naver.com. Los datos se eliminan en un plazo de 30 días.

6. Seguridad

Los datos se almacenan en Firebase con reglas de seguridad que garantizan que solo el autor puede editar o eliminar sus reseñas.
