🛡️ 핵심 원칙

Moni는 사용자의 재무 데이터를 개발자 서버로 전송하거나 수집하지 않습니다.
모든 데이터는 기기 내부 또는 사용자 본인의 iCloud 개인 데이터베이스에만 저장됩니다.

📂 수집하는 데이터

수집하지 않습니다.

거래 내역, 계좌 정보, 예산, 저축 목표 등 앱 내 모든 재무 데이터는 다음 두 곳에만 저장됩니다.

  • 온디바이스 — SwiftData (기기 내 SQLite)
  • 사용자 iCloud — CloudKit 개인 데이터베이스 (개발자 접근 불가)

개발자는 사용자 데이터에 접근하거나 열람할 수 없습니다.

🔄 외부 네트워크 요청

앱이 외부에 연결하는 경우는 환율 조회 한 가지뿐입니다.

  • 서버: open.er-api.com
  • 전송 내용: 기준 통화 코드만 (예: MXN)
  • 사용자 식별 정보 일절 미포함
  • 해당 서비스의 개인정보처리방침

📷 카메라 권한

영수증 스캔 기능에서 카메라를 사용합니다. 촬영한 이미지는 기기 내에서 텍스트 인식(Vision 프레임워크)에만 사용되며, 외부로 전송되지 않습니다.

선택적 권한 — 사용하지 않으면 요청되지 않습니다.

🔒 Face ID / Touch ID

앱 잠금 기능에서 생체 인증을 사용합니다. 생체 정보는 Apple의 Secure Enclave에서 처리되며, Moni 앱은 생체 데이터에 접근할 수 없습니다.

선택적 기능 — 앱 잠금 설정 시에만 활성화됩니다.

☁️ iCloud / CloudKit

CloudKit 동기화를 활성화하면 데이터가 사용자 본인의 iCloud 계정(Apple ID)에 저장됩니다. 이 데이터베이스는 완전히 비공개이며, 개발자는 접근 권한을 가지고 있지 않습니다.

iCloud 동기화는 기기의 설정에서 언제든지 비활성화할 수 있습니다.

👨‍👩‍👧 Family Sharing

Family Sharing 기능을 사용하면 구성원 간 거래 데이터를 공유할 수 있습니다. 이 데이터는 Apple의 iCloud 인프라를 통해서만 전달되며, 개발자 서버를 경유하지 않습니다.

🔔 알림

예산 초과, 저축 목표, 지출 이상 감지 등의 알림은 기기 내에서 생성되며 외부 서버를 사용하지 않습니다. 알림 권한은 설정에서 언제든지 변경할 수 있습니다.

👶 아동 개인정보

Moni는 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

🛡️ Core Principle

Moni does not transmit or collect your financial data on any developer-controlled server.
All data is stored exclusively on your device or in your own private iCloud database.

📂 Data We Collect

We collect nothing.

All financial data (transactions, accounts, budgets, savings goals) is stored only in:

  • On-device — SwiftData (local SQLite database)
  • Your iCloud — CloudKit private database (inaccessible to the developer)

The developer has no access to your data at any time.

🔄 External Network Requests

The only external connection Moni makes is to fetch exchange rates.

  • Server: open.er-api.com
  • Sent: base currency code only (e.g. MXN)
  • No personally identifiable information is ever sent
  • See their privacy policy

📷 Camera Access

The camera is used for the receipt-scanning feature. Images are processed on-device using Apple's Vision framework for text recognition only. No images are uploaded or transmitted.

Optional permission — only requested when you use the scanner.

🔒 Face ID / Touch ID

Biometric authentication is used for the App Lock feature. Biometric data is handled entirely by Apple's Secure Enclave. Moni has no access to your biometric data.

Optional feature — only activated when App Lock is enabled.

☁️ iCloud / CloudKit

When iCloud sync is enabled, your data is stored in your own iCloud account (Apple ID). This database is fully private — the developer has no access to it whatsoever.

You can disable iCloud sync at any time from your device's Settings.

👨‍👩‍👧 Family Sharing

Family Sharing allows transaction data to be shared among family members. Data flows exclusively through Apple's iCloud infrastructure and never passes through developer-controlled servers.

🔔 Notifications

Budget alerts, savings goal reminders, and spending anomaly notifications are generated on-device without any external server. You can change notification permissions at any time in Settings.

👶 Children's Privacy

Moni is not directed at children under 13, and we do not knowingly collect personal information from children.

🛡️ Principio fundamental

Moni no transmite ni recopila tus datos financieros en ningún servidor controlado por el desarrollador.
Todos los datos se almacenan exclusivamente en tu dispositivo o en tu propia base de datos privada de iCloud.

📂 Datos que recopilamos

No recopilamos nada.

Todos los datos financieros (transacciones, cuentas, presupuestos, metas de ahorro) se almacenan únicamente en:

  • En el dispositivo — SwiftData (base de datos SQLite local)
  • Tu iCloud — Base de datos privada de CloudKit (inaccesible para el desarrollador)

El desarrollador no tiene acceso a tus datos en ningún momento.

🔄 Solicitudes de red externas

La única conexión externa que realiza Moni es para obtener tipos de cambio.

  • Servidor: open.er-api.com
  • Se envía únicamente el código de la moneda base (p. ej. MXN)
  • No se envía ninguna información de identificación personal
  • Consulta su política de privacidad

📷 Acceso a la cámara

La cámara se utiliza para la función de escaneo de recibos. Las imágenes se procesan en el dispositivo mediante el framework Vision de Apple únicamente para reconocimiento de texto. No se suben ni transmiten imágenes.

Permiso opcional — solo se solicita cuando usas el escáner.

🔒 Face ID / Touch ID

La autenticación biométrica se utiliza para la función de bloqueo de la app. Los datos biométricos son gestionados completamente por el Secure Enclave de Apple. Moni no tiene acceso a tus datos biométricos.

Función opcional — solo se activa cuando el bloqueo de app está habilitado.

☁️ iCloud / CloudKit

Cuando la sincronización con iCloud está activada, tus datos se almacenan en tu propia cuenta de iCloud (Apple ID). Esta base de datos es completamente privada: el desarrollador no tiene acceso a ella en absoluto.

Puedes desactivar la sincronización con iCloud en cualquier momento desde la Configuración de tu dispositivo.

👨‍👩‍👧 Compartir en familia

La función de Compartir en familia permite compartir datos de transacciones entre los miembros. Los datos fluyen exclusivamente a través de la infraestructura iCloud de Apple y nunca pasan por servidores del desarrollador.

🔔 Notificaciones

Las alertas de presupuesto, recordatorios de metas de ahorro y notificaciones de anomalías de gasto se generan en el dispositivo sin ningún servidor externo. Puedes cambiar los permisos de notificación en cualquier momento desde Configuración.

👶 Privacidad de los menores

Moni no está dirigida a menores de 13 años y no recopilamos conscientemente información personal de niños.
